G-push プログラムの確認手順（Teikyo2026 提出版）
================================================

1. 概要
Owner が提出用に選定した RC16 のインストーラと対応ソース ZIP を収録しています。
本書の提出物配置・版番号と、未確認の製品機能を区別して記載しています。

2. 必要な環境
・Windows
・G-push アカウント（サインインなどの機能確認は未確認です）
・Blender 4.5 系（提出アセットの読み込みは 4.5.12 で確認済み）

3. インストール
同じフォルダの G-push-Setup.exe を実行し、セットアップ画面に従います。
RC16 の実生成・Owner の実機インストール成功・後続起動成功は既存の Owner 報告です。
Preview 公開成功も既存報告として記録されています。今回の自動再検証結果ではありません。

4. 起動・サインイン
インストール後に G-push を起動します。Owner の後続起動成功と、
サインイン・セッション継続・アカウント作成の機能合格は別の確認項目です。
認証機能の合格は未確認です。失敗時は操作と表示されたエラーコードを記録してください。

5. Project / Worker
Project 入力、検査、アップロード保存、Worker 登録・実行、結果確認、Community は未確認です。
インストール成功や本書だけを、これらの処理成功の証明として扱わないでください。

6. Blender での確認
05_Blender確認用/README_Blender確認.txt を参照してください。
Blender 4.5.12 でのローカル読み込みと未解決依存関係 0 件が既存の確認範囲です。
G-push へのアップロードや処理成功を示すものではありません。

7. 確認範囲
提出フォルダに本体・対応ソース・文書・動画・資料・Blender アセットを配置しています。
動画は解説用であり、現行ソフトウェアの機能合格や製品 E2E の証明ではありません。

8. ソース・ビルド・実行
G-push-source.zip は下記コミットの収録済みソースエクスポートです。
221 エントリ、展開後 6,078,162 bytes の既存の展開・監査記録を使用しています。
ZIP 内のビルド手順書を参照してください。外部の Node、Electron、NSIS 等は同梱していません。
所有者指定により realm 設定と builder 設定は同梱対象外です。
ネイティブバイナリの完全な再現ビルドは NOT_PROVEN です。今回、再エクスポートや再ビルドはしていません。

10. 困ったとき
ファイル同一性は提出物ルートの SHA256SUMS.txt と SUBMISSION_MANIFEST を参照してください。
Blender の読み込み時にエラーが出た場合は保存せず、エラーを確認担当者に伝えてください。
パスワード、トークン、認証コード、個人情報を報告文に含めないでください。
設定変更、SQL、開発者ツール、検証回避の操作は本手順には含めません。
